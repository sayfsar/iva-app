Iva Assistant

Iva Assistant is a private, single-user AI assistant that runs on its owner's own server and is used through Telegram. It is not a public service and is not offered to other users.

With the owner's permission it can read and manage the owner's own Gmail, Google Calendar, Google Tasks, Google Drive, Docs and Sheets — for example, to summarize mail, create calendar events and set reminders.
