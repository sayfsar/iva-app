# iva-app

Public GitHub Pages site (https://sayfsar.github.io/iva-app/) with the home page
and privacy policy required by Google Cloud to put the "Iva Assistant" OAuth app
(project `iva-assistant-513111`) into "In production" status.

- `index.html` — app home page
- `privacy.html` — privacy policy

The repo is PUBLIC: never commit keys, tokens or personal data here.
The Iva assistant itself runs on the Hetzner VPS (see the user's memory notes).
